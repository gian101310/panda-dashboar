PANDA STANDALONE RAW SCORE - MT4 (v1.20)

Copy PandaStandaloneScoringMT4.ex4 into MT4's Data Folder > MQL4 > Indicators.
Refresh Navigator and attach it to a chart for one of Panda's 21 currency pairs.

The panel shows current and ADV net D1, H4, and H1 currency scores.
It calculates directly from MT4 broker prices and H1 history, using the same
box windows and vote totals as Scoring with Adv v1 MT4.

No MT4 export files, Panda engine, other indicator, EA, token, or web access.
It does not draw boxes or show gap, bias, ATR, or spread.

The narrow strip at the top of the panel can be dragged. PanelX and PanelY
set its initial position; by default it starts near the bottom right.
Ensure the broker has H1 history for all 21 pairs. Compare with the original
Scoring with Adv v1 MT4 on the same broker and at the same time.
